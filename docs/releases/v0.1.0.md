# Release v0.1.0 — initial working prototype

**Date:** 2026-10-22  
**Status:** generated and locally verified for NumPy backend; Qiskit and multi-OS acceptance outstanding.

## Added

- Importable Python `quantum_workbench` package and `qworkbench` CLI; semantic package version `0.1.0`.
- Circuit API for common gates, rotations, custom small unitaries, measures, resets, and named subcircuit expansion metadata.
- Pluggable small-state NumPy and optional Qiskit Statevector backends.
- Validated Qiskit circuit import/export subset and explicit rejection of unsupported dynamic operations.
- Gate-by-gate execution trace, exact classical measurement branches and conditional amplitudes, reset branches, and seeded sampling.
- Examples: Bell, GHZ, uniform register (including seven-wire 128-outcome test), QFT/inverse QFT, known-eigenstate phase estimation, mid-measurement, reset.
- Correct little-endian qubit conventions, configurable guardrails, exact qubit marginals, top-k/Other accounting.
- Static Matplotlib PNG/SVG output, versioned JSON trace export, optional full per-branch amplitude export.
- Design documents, examples, unit/integration tests, and a guided local acceptance checklist.

## Decisions

Qiskit **SDK** is used as an optional independent Statevector backend and as a circuit interoperability adapter. NumPy is the self-contained reference backend that is fully testable when external packages are unavailable. No Aer or cloud account. No GUI yet; the CLI and figure exports are the working educational prototype. Branch tracking is capped to prevent explosive memory use.

## Verification at package creation

- `PYTHONPATH=src MPLBACKEND=Agg pytest -q`: **35 passed, 1 skipped module** (Qiskit optional tests unavailable).
- Bell 00/11 probabilities, seven-qubit GHZ, 128-outcome uniform distribution, QPE theta=1/8 phase-register `001`, inverse-QFT composition, reset/measurement behavior checked.
- Command-line demo and PNG/JSON export tested with local installed NumPy/Matplotlib/pytest.
- Qiskit backend, true `uv sync`, wheel build, Ruff, and macOS/Windows operation **not verified** in the packaging environment because package-index DNS resolution failed. User validation steps in `docs/testing-v0.1.md`.
- First online `uv sync` will produce a genuine `uv.lock`, which should be committed to the user's repository.

## Known limitations

No browser interactive UI; no Shor factorization/oracles; no general classical feedforward or dynamic circuits; no noise channels; no density matrix presentation; no QKD, quantum communications or QEC simulator. QFT and QPE examples are educational gate-level programs. Custom unitary matrices capped at 8 qubits. Exact branching may require substantial memory. Rendered circuit plot is a static timeline, not an advanced circuit editor.

## Next release candidate (v0.2)

Focus on GUI hierarchy, interactive trace selection, branch navigation, editable gate placement (potentially follow-up), selected-register histogram, and QPE visualization. Use user acceptance feedback from v0.1 as the priority input; do not prematurely commit to a browser implementation without testing.
